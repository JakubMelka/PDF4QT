## Overview

PDF4QT 1.4.0 resolves 18 issues: a dark mode, the alternative software rendering backend Blend2D, pictures added to documents, an option to ignore the security settings of a PDF, trusted certificates, an AppImage for each application, access keys of menu items and fixes of form fields, stamps and rendering.

## Fixed issues

- #190 · PageMaster crash + black bubbles instead of bubbles with correct color
- #184 · Form field font size too large
- #183 · Option to ignore PDF security settings
- #182 · PDF4QT Document Diff command line cmd line arguments ignored
- #181 · where is the dark mode?
- #180 · PDF4QT editor and options windows higher than desktop
- #174 · Support for Linux seems to be very limited
- #173 · errors loading file Echoplex.pdf
- #172 · access keys are missing from most menu items/action text strings
- #168 · When opening a PDF file or merging some PDF files, stamp will disappear.
- #166 · Adding images to PDF?
- #164 · Taskbar icon not shown in linux mint.
- #163 · Unable to render probably valid PDF
- #161 · Can it be possible to trust a certificate like in acrobat?
- #159 · Offer 4 AppImage one for each App [enhancement]
- #123 · Alternative software rendering backend (Blend2D)
- #42 · Is REAL pdf text editing planned ?
- #26 · Add pictures in PDF files
