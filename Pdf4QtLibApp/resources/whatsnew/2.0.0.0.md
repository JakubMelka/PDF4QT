## Overview

PDF4QT 2.0 is not released yet. It replaces Editor, Viewer, PageMaster, Diff and LaunchPad with one application with tabs, brings the first tools of its tool catalog, and it resolves 40 issues reported on GitHub so far, listed below.

## Highlights

### Unlock by the owner password
icon: unlock · hue: red
A document, which does not allow printing, copying or changes, asks for its owner password when you need such an action. It stays unlocked until you close it, and its encryption and permissions are kept when you save it. Assistants never get the password.

### Cancel after every run
icon: x-circle · hue: neutral
After a run, every tool keeps its Cancel button, so you can close it without deciding about the result. The button, which started the run, stays in its place, disabled.

### Certified documents only as a copy
icon: certificate · hue: amber
A tool, which inserts, removes, rotates, crops or resizes pages, never changes a certified document in place – its certification would be broken. It offers only Save as a copy, written whole without the signatures.

### Separate files done right
icon: split-pages · hue: blue
PageMaster numbers the file names by every # of the template, gives each group its own number and keeps the order of the pages you type. PdfTool separate puts only the pages of each file into it, checks the pages you ask for and the permission to assemble the document, and reports an error by its exit code.

### Manage Pages replaces PageMaster
icon: grid · hue: violet
Manage Pages reorders, groups, clones and rotates the pages of many files and creates one PDF, a PDF per group or a PDF per page. Started over an open document, it rearranges that document and keeps its signatures. An assembly is saved as a .pdf4qtassembly file; PageMaster workspaces (.pagemaster) are not opened.

### Passwords and certificates
icon: shield-lock · hue: teal
Protect with Password, Restrict Permissions, Encrypt with Certificate and Remove Password encrypt the whole document, everything but its metadata or only its attachments, show how strong a password is and create or import certificates. Only the owner changes the security of a document. A file encrypted by the old Editor or PdfTool with an open password only could be opened by anyone as its owner; now the open password is the owner password too.

### PdfTool encrypt and decrypt
icon: terminal · hue: neutral
encrypt with --enc-user-password alone allows everything; restrictions need an owner password of their own (exit code 13), --enc-permissions is normalized by ISO 32000-2 Table 22 and an empty owner password is the open password. encrypt writes the document ID, raises the PDF version as the algorithm needs it, encrypts attachments without their type too, removes the PDF/A declaration (with a note on the error output), fails on a stream it cannot decrypt and reads the result back. decrypt leaves no old encryption in the file and reads the result back.

### Signatures you can trust
icon: signature · hue: teal
Sign with Certificate signs with a .pfx file or a certificate of the Windows certificate store, in the PAdES format or the compatible PKCS#7 format, visibly or invisibly, into a new or an empty signature field, optionally with a timestamp of an authority. Add Timestamp adds a document timestamp, Sign by Hand draws a signature on the pages and Manage Certificates keeps your certificates and the trusted ones in one tab. The signed copy is the exact file with an incremental update, so the earlier signatures stay valid. The Signatures panel names the signer by the certificate, which really made the signature, and reports every change made after signing; known attacks on signed documents are never shown as a clean signature.

### Redaction that removes
icon: redact · hue: red
Redact Content marks areas, text, whole pages or every match of a search and creates a redacted copy: every page is rebuilt, the pixels of images below the marks are removed, and the copy is checked before it is offered. The open document keeps its marks as redaction annotations, and the search term is never remembered.

### PdfTool redact, verify-signatures and cert-store
icon: terminal · hue: neutral
redact uses the Redact Content tool of the application with its check of the copy and takes the common options (--pswd, --no-permissive-reading, --console-format, --text-codec and the color management options); a restricted document needs its owner password. verify-signatures names the signer by the certificate of the signature and checks the signed byte ranges exactly. cert-store keeps its file of trusted certificates with limits of its size.

### Review and inspect
icon: bar-chart-2 · hue: violet
Document Statistics, Object Inspector and Document Report show what is inside a file, Ink Coverage, Output Preview and Soft Proofing check it for print. None of them changes the document. A damaged or hostile file is shown safely: streams are decoded only up to a limit and in the background, scripts are listed but never run.

### Print production checks
icon: separations · hue: teal
Output Preview and Ink Coverage render the page as it is printed: the annotations, which are printed, are included, and overprint follows ISO 32000-2 – the nonzero overprint mode applies only to DeviceCMYK colors in a DeviceCMYK group, never to images, shadings or the compositing of a group. A page group in RGB is measured in the process inks, the colorant None paints nothing and All marks every spot ink too. The coverage ratio is measured inside the TrimBox (else the CropBox), and the total no longer counts the first page of an ink twice. Soft Proofing shows the proof only in the tab; printing, exports and thumbnails never have it.

### Statistics and reports you can trust
icon: report · hue: blue
Document Statistics no longer writes outside of its memory on a page, whose contents point to a missing object, and it puts every object into exactly one class. Document Report lists the scripts of the open action, of the additional actions, of the outline, of chained actions (/Next) and of XFA forms. A document is reported as tagged only by /MarkInfo /Marked – the same in Properties, in the report and for assistants – and /Trapped is no longer shown as Tagged. The ASCIIHexDecode filter reads an odd number of digits and white space as ISO 32000-2 says, and RunLengthDecode never reads past the end of its data.

### PdfTool review commands
icon: terminal · hue: neutral
statistics, info, info-fonts, info-dests, info-javascript, info-metadata, xml, ink-coverage and info-inks share their data with the tools of the application, and their numbers and dates no longer depend on the language of the system. statistics has the row File structure and one class for every object; info shows trapped, tagged and encryption-revision separately and the page sizes with /UserUnit; info-fonts finds the fonts of forms, appearances, patterns and Type 3 fonts; info-dests marks a destination, whose page does not exist, as unresolved; info-javascript lists the scripts of the open action, the additional actions, the outline, chained actions and XFA forms; info-metadata and xml decode streams only up to a limit and report a stream, which cannot be decoded; ink-coverage writes the columns inkN-area and inkN-ratio and the row Total and measures the ratio inside the TrimBox; info-inks lists every spot ink. statistics says "Repaired when opened" for a damaged file, which had to be restored to be read; xml writes real numbers without a loss of precision. A page range outside of the document ends with exit code 7, --text-codec accepts UTF-8 and errors go to the error output. info-javascript, info-metadata and xml with the data of the streams accept the owner password by --pswd, when the document has no open password. Like fetch-text, info-javascript, info-metadata and xml with the data of the streams end with exit code 9, when the document does not allow copying its content and was not opened by its owner password.
