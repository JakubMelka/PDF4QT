## Overview

PDF4QT 1.6.0 resolves 42 issues reported on GitHub: links to internal objects of the document, full screen, snapping, a wildcard mode of Advanced Find and searching by the Enter key, side-to-side scrolling, a color blend mode for highlights, bulk editing of page labels, a custom settings directory and fixes of fonts, checkboxes, embedded files and undo in page content editing.

## Highlights

### Links to internal objects
icon: link · hue: blue
Hyperlinks can point to internal objects of the PDF (issue #389).

### Full screen
icon: maximize · hue: violet
Documents can be shown in full screen (issue #242).

### Wildcard search
icon: wildcard · hue: amber
Advanced Find has a wildcard mode and starts searching by the Enter key (issues #379 and #378).

### Highlight blend modes
icon: highlighter · hue: green
Highlights can use a color blend mode (issue #354).

### Page labels in bulk
icon: label · hue: red
Page labels can be deleted, added and edited in bulk (issue #357).

### Custom settings directory
icon: settings · hue: neutral
PDF4QT can run with a custom settings directory given on the command line (issue #380).
