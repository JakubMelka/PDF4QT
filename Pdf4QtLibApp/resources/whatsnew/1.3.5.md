## Overview

PDF4QT 1.3.5 resolves 6 issues: text to speech on Linux, text selection, hot reload of the document, a faster optimizer of large files and fixes of reading and decompressing documents.

## Fixed issues

- #65 · Text2Speech doesn't work on Linux
- #72 · Cannot select text
- #82 · Hot reload function
- #80 · Optimizer is slow on large PDF files
- #77 · Document read error
- #78 · Error decompressing stream
