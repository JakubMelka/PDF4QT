## Overview

PDF4QT 1.5.2 resolves 11 issues: the history of recent files can be cleared, DocPage Organizer uses file names instead of titles, a Russian translation, redaction annotations in PdfTool, a page layout, which persists between files, scaling of dimensions, installed API headers and the direction of lines locked by a key.

## Fixed issues

- #313 · Remove history UX improvement
- #310 · Docpage organiser uses PDF title rather than filename
- #306 · Unable to delete the recent files history.
- #303 · Add Dockerfile for Simplified PDF4QT Setup with Qt 6.9.1 and All Dependencies
- #301 · Russian Language file
- #296 · Redaction annotation support in PdfTool
- #295 · Request: Make page layout choice persist between files
- #279 · qt_add_translations uses options only in qt 6.9
- #284 · Scaling dimensions [Enhancements, Features]
- #281 · install API headers for reuse by other applications ?
- #251 · Let user lock direction of lines/polylines when pressing keybinding (e.g. shift)
