## Overview

PDF4QT 1.5.0 resolves 13 issues: the color and intensity of highlights, reversing of the page order, zoom anchored to the cursor, pictures added to documents, white, whitesmoke and transparent annotations, trusted certificates, outlines kept by PageMaster and fixes of raster content, dark theme icons on KDE and builds on Linux.

## Fixed issues

- #244 · PageMaster: united one document after remove pages leads to lose the outline
- #236 · Highligting - Allow color selection and intensity [Enhancement]
- #229 · Can't add picture to PDF
- #228 · [feature] reverse pages order
- #222 · UnitTests fails several tests
- #207 · Zoom to Cursor (Zoom Anchoring)
- #206 · Name of the executable / command
- #205 · Editor cannot create white, whitesmoke or transparent annotations
- #202 · Certain raster content not rendered
- #200 · Icons under dark theme on Arch/KDE is broken
- #185 · Latest git fails to build in linux
- #165 · Insert > Inline Text latency issues on Flatpak and Appimage packages
- #161 · Can it be possible to trust a certificate like in acrobat?
