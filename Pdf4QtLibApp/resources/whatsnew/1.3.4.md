## Overview

PDF4QT 1.3.4 resolves 8 issues: a redesigned sidebar, highlighting of text, which no longer opens the sidebar, fixes of mirrored pages, dashed lines and font encodings, an alternative vcpkg file and documents, which did not open.

## Fixed issues

- #75 · Redesign of sidebar widget
- #74 · Highlighting text opens the sidebar every time
- #73 · Minor GUI issues
- #71 · Pages are "mirrored"
- #69 · Dashed Line not rendered as expected
- #68 · Add alternative VCPKG file with dependency on Qt
- #59 · Fix character font encoding - do not use (1, 0) Mac Roman table if (3, 1) unicode table is present (according to spec)
- #50 · Some types of pdf don't open as expected and some doesnt open.
