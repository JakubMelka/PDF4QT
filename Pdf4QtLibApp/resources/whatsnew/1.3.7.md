## Overview

PDF4QT 1.3.7 resolves 21 issues: a search bar for actions, an improved search bar, smooth scrolling, a list of markup annotations, bookmarks for pages, a redesigned sidebar with new icons, icons for dark mode, a Save button in the toolbar and CMake options for minimal builds.
