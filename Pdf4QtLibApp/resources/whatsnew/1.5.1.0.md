## Overview

PDF4QT 1.5.1 resolves 6 issues: the license changes to MIT, the light or dark mode can be forced, invert selection works in PageMaster, the units settings window is larger, the About page shows the current version and year and the cross can be hidden when annotations are added.

## Fixed issues

- #271 · Change of the license to MIT
- #257 · Force light mode (or dark mode)
- #255 · PDF4QT Page Master invert selection does not work
- #254 · Unit Settings default window size too small
- #248 · update version and year in Help > About page
- #247 · option to hide cross when adding annotations
