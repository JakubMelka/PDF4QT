## Overview

PDF4QT 1.3.6 resolves 12 issues: editing of the outline, accessibility options, documents created from converted bitonal images, highlight rectangles, drag and drop in DocPage Organizer, a new directory structure and a fix of Send by Email in PDF4QT Viewer Lite.

## Fixed issues

- #110 · PDF4QT Viewer Lite : Arbitrary Code can execute when using Send by Email
- #109 · No text, font. Parts missing
- #108 · Add accessibility options in pdf reader
- #107 · Create document with converted bitonic images
- #106 · Warning - Hardware acceleration is not supported on this device
- #103 · Bookmark sidebar greyed out if a bookmark is not already present
- #100 · Highlight rectangle
- #97 · Add drag and drop capability to DocPage Organizer, Context menu + layout items on window size changed
- #94 · New directory structure
- #83 · Is it possible to specify a default font for a pdf when the font is not load or recognize?
- #76 · Outline editing
- #58 · PDF Doc with rotated type3 fonts
