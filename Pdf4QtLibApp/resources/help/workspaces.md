A workspace is a named set of documents, which you open together, for example all documents of one project.

## Restore the last session

The first row of **Workspaces** on the pages Open and Recent is **Restore last session**. It shows how many documents were open, when PDF4QT was closed last time. **Restore** opens all of them again, each in its own tab and at its page.

## Save a workspace

1. Open the documents, which belong together.
2. On the page Open, click **Save open documents as workspace…** (it is available, when a document is open).
3. In **Save as workspace**, enter the **Name** of the workspace and check the **Documents**, which belong to it, then click **Save**.

When a workspace of the same name exists already, the dialog says so: choose another name, or **Replace** the existing workspace.

A workspace keeps the files and their pages, not unsaved changes: a document with unsaved changes is marked *Unsaved changes* in the list, and the saved file is used. A document, which has not been saved to a file yet, must be saved first.

## Open, rename and delete a workspace

- Click a workspace to open all its documents.
- The button **⋮** of a workspace has **Open**, **Rename…** and **Delete…**. Deleting a workspace never deletes its documents.
- **Manage** at the section Workspaces shows all workspaces on the page Recent.

## Pinned locations

**Pinned Locations** on the page Open are folders you use often, for example a folder of a project or a cloud drive. **Add…** chooses a folder in the dialog of your system; the star of a folder in [Recent](/recent?filter=folders) pins it too.

Click a pinned location to choose files in it. Its menu **⋮** has **Browse files here…**, **Show in Folder**, **Copy Path**, **Rename…** (only the name shown in PDF4QT changes, not the folder) and **Remove from Pinned Locations**.
