[Settings](/settings/general) has nine sections. Changes are saved automatically and apply to all open windows of PDF4QT at once.

## The sections

| Section | What you set there |
| --- | --- |
| General | Language, appearance, documents, tools and updates |
| Viewing | Page display, scrolling and the magnifier |
| Color modes | Reading colors and contrast |
| Editing | Undo, the author of annotations and forms |
| Security | Links, signatures and certificates |
| Speech | The voice for reading aloud |
| Shortcuts | Keyboard shortcuts, see [Keyboard shortcuts](/help/keyboard-shortcuts) |
| Color management | The color engine and ICC profiles |
| Advanced | The rendering engine, the cache and the developer options |

## Find a setting

Type into **Search settings…** at the top of the list of sections. The sections and the settings, which do not match, are hidden. The global search (**Ctrl+K**) finds settings as well and opens the section at the setting.

## Restore the defaults

**Restore defaults** at the top of a section returns all settings of the section to their default values, after you confirm it. It is disabled, when nothing of the section has been changed.

> [!NOTE] Language
> The language of the user interface is English by default. Another language is applied after PDF4QT is started again.
