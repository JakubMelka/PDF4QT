[Settings](/settings/general) has ten sections. Changes are saved automatically and apply to all open windows of PDF4QT at once.

## The sections

| Section | What you set there |
| --- | --- |
| General | Language, appearance, documents, tools and updates |
| Viewing | Page display, scrolling and the magnifier |
| Color modes | Reading colors and contrast |
| Editing | Undo, the author of annotations and forms |
| Security | Links, signatures and certificates |
| Speech | The voice for reading aloud |
| Shortcuts | Keyboard shortcuts, see [Keyboard shortcuts](/help/keyboard-shortcuts) |
| Color management | The color engine and ICC profiles |
| Advanced | The rendering engine, the cache and the developer options |
| Storage | Where the settings are saved, their backup and the files of other versions, see [Where your data is stored](/help/data-storage) |

## Find a setting

Type into **Search settings…** at the top of the list of sections. The sections and the settings, which do not match, are hidden. The global search (**Ctrl+K**) finds settings as well and opens the section at the setting.

## Restore the defaults

**Restore defaults** at the top of a section returns all settings of the section to their default values, after you confirm it. It is disabled, when nothing of the section has been changed.

## Language

**Language** in [General](/settings/general#language) changes the language of the user interface at once, in all windows; dates, times and numbers follow it. **Automatic** uses the language of your system, when PDF4QT has its translation, and English otherwise.

> [!NOTE] Translations
> The language of the user interface is English by default. Texts, which are not translated yet, are shown in English. When the translation file of a language is missing or damaged, PDF4QT is shown in English and the row Language says so.

## Tool history

PDF4QT counts which tools you run after each other, so that “Then continue with” can suggest the next tool. Only tool identifiers and counts are kept, never file names. **Clear history…** in [General](/settings/general) deletes the counts after you confirm it; your pinned tools, collections and the list of recently used tools stay. Turn off **Suggest tools I often use next** to stop counting.
