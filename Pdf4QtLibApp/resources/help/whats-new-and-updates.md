The page [What's New](/whats-new) shows what changed in the version you are running: its overview, the highlights, the new tools and the fixed issues. **Read full release notes** opens all notes of the release.

## Earlier versions

The card **Version history** lists the releases. Click a version to see its changes; **View all** shows the whole list and **Show less** collapses it again. The version you are running has a dot.

## Check for updates

PDF4QT asks GitHub at most once a day, whether a newer version is available. It only shows the answer: nothing is downloaded or installed, and no window or notification opens. The card **Update status** on What's New shows the result:

| State | Meaning |
| --- | --- |
| You're up to date | The version you are running is the latest release |
| Checking for updates… | PDF4QT is asking GitHub right now |
| PDF4QT … is available | A newer version exists; **Download from GitHub** opens the page of the release |
| Could not check for updates | GitHub could not be reached; **Try Again** asks again |
| Automatic check is off | PDF4QT checks only, when you click **Check for updates** |

When more windows of PDF4QT are open, only one of them asks GitHub and the others show its result.

> [!NOTE] What is sent
> The request asks GitHub for the latest release of PDF4QT. It identifies itself only as PDF4QT and its version, and it sends no cookies.

## Turn the automatic check off

Open [Settings › General](/settings/general#check-for-updates) and turn off **Check for updates automatically**. You can still check at any time by **Check for updates** on What's New.
