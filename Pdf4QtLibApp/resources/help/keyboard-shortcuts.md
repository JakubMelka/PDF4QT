These shortcuts work in the whole window. You can change each of them in [Settings › Shortcuts](/settings/shortcuts).

## Window

| Command | Shortcut |
| --- | --- |
| New tab | Ctrl+T |
| Close tab | Ctrl+W |
| Next tab | Ctrl+Tab |
| Previous tab | Ctrl+Shift+Tab |
| Quit | Ctrl+Q |

## File

| Command | Shortcut |
| --- | --- |
| Open… | Ctrl+O |

## Navigation

| Command | Shortcut |
| --- | --- |
| Back | Alt+Left |
| Forward | Alt+Right |
| Search | Ctrl+K |
| Help | F1 |

The back and forward buttons of the mouse go back and forward as well.

## Change a shortcut

1. Open [Settings › Shortcuts](/settings/shortcuts).
2. Click the shortcut of the command and press the new combination of keys.
3. When another command already uses the combination, PDF4QT tells you, which one it is.

> [!NOTE] Lists, buttons and fields
> **Tab** and **Shift+Tab** move the keyboard focus between the parts of a page, **Enter** and **Space** activate the focused row, button or link.
