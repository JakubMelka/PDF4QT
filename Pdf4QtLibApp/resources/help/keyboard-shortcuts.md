These shortcuts work in the whole window. You can change each of them in [Settings › Shortcuts](/settings/shortcuts).

## Window

| Command | Shortcut |
| --- | --- |
| New tab | Ctrl+T |
| Close tab | Ctrl+W |
| Next tab | Ctrl+Tab |
| Previous tab | Ctrl+Shift+Tab |
| Quit | Ctrl+Q |

## File

| Command | Shortcut |
| --- | --- |
| Open… | Ctrl+O |

## Navigation

| Command | Shortcut |
| --- | --- |
| Back | Alt+Left |
| Forward | Alt+Right |
| Search | Ctrl+K |
| Help | F1 |

The back and forward buttons of the mouse go back and forward as well.

In the list of results of the [search](/help/search), **Up** and **Down** move between the results, **Enter** opens the selected result, **Ctrl+Enter** shows all results on their own page and **Esc** closes the list.

## Document

These shortcuts work in the tab of a document.

| Command | Shortcut |
| --- | --- |
| Save | Ctrl+S |
| Save as… | Ctrl+Shift+S |
| Print… | Ctrl+P |
| Document properties | Ctrl+D |
| Undo | Ctrl+Z |
| Redo | Ctrl+Y |
| Find in document | Ctrl+F |
| Find next | F3 |
| Find previous | Shift+F3 |
| Go to page… | Ctrl+G |
| Hand | Ctrl+H |
| Add bookmark | Ctrl+M |
| Next bookmark | Ctrl+. |
| Previous bookmark | Ctrl+, |
| Rendering issues | Ctrl+E |

On macOS the shortcuts with Ctrl use the Command key (⌘); the shortcut of **Hand** is Control+H there, because Command+H hides the application.

| Command | Shortcut |
| --- | --- |
| Rename outline item | F2 |

## Change a shortcut

1. Open [Settings › Shortcuts](/settings/shortcuts).
2. Click the shortcut of the command and press the new combination of keys.
3. When another command already uses the combination, PDF4QT tells you, which one it is.

> [!NOTE] Lists, buttons and fields
> **Tab** and **Shift+Tab** move the keyboard focus between the parts of a page, **Enter** and **Space** activate the focused row, button or link.
